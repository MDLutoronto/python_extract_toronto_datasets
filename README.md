# Python Scripts for Extracting Toronto Data

You can find various scripts for extracting Toronto-specific datasets from larger provincial or national datasets.

## Business
### Data Axle
Historical business data (2009-) covering Canadian businesses. This script extracts a subset of just Toronto businesses.
* [Data Axle Python Script](data_axle_microdata_extract.py)

## Education
### Enrolment Data
From Open Ontario, a dataset covering enrolment data 
* [Enrolment Data Python Script](enrolment_data_extract.py)

## Housing
### BCPI - Building Construction Price Index
Extract Toronto-specific data from the BCPI (uses CMA). Public use microdata from contractor survey responses.
* [BCPI Python Script](bcpi_microdata_extract.py)

### NCAPI - New Condominium Apartment Price Index
* [New Condominium Price Index Python Script](ncapi_microdata_extract.py)

## Government
### SLA - Service Level Agreement 
Information on quarterly transfer payment agency metrics. 
* [Service Level Agreement Python Script](extract_sla_data.py)

## Income & Labour 
### CIS - Canadian Income Survey
Annual cross-sectional survey drawn as a sub-subsample of the Labour Force Survey (LFS) covering income, low income/inequality, 
housing, labour, disability, health care, and food security
* [CIS Python Script](cis_microdata_extract.py)

### LFS - Labour Force Survey
* [Labour Force Survey Python Script](lfs_microdata_extract.py)
